# Inkpaper 纸墨（Figma 印刷导出插件）

> 名字取自 ink（油墨）+ paper（纸），中文「纸墨」：把屏幕上的设计，变成纸上的墨。

在 Figma 里做印刷排版，按印刷厂要求配置和检查输出文件，包括：
- **色彩**：CMYK / ICC 色彩管理、专色、叠印、总墨量控制
- **版面**：出血、裁切线
- **包装**：刀版
- **拼版**：骑马钉、一版多拼、正反面
- **格式**：PDF/X-4 / X-1a / X-3、CMYK TIFF / JPEG

**所有处理都在本机完成，设计稿不会上传到任何服务器。**
界面支持 8 种语言：简体中文、繁體中文、English、日本語、한국어、Español、Deutsch、Français。

## 安装（开发版）

1. Figma 桌面版 → 菜单「插件 Plugins」→「开发 Development」→「从清单导入 Import plugin from manifest…」
2. 选择本文件夹里的 `manifest.json`
3. 以后在「插件 → 开发」里运行「Inkpaper 纸墨」

> 导入开发插件需要 Figma 的完整席位（Full seat）。

## 第一次使用

在欢迎页，或「设置 → 印刷方案与 ICC」中导入印刷厂给的 ICC 配置文件，也可从导出页的印刷方案进入。
- **国内胶印**：一般用 Japan Color 2001 Coated
- **欧洲**：FOGRA39 / PSO Coated v3
- **北美**：GRACoL / SWOP

免费下载渠道：Adobe ICC 配置文件包、ECI 配置文件。导入一次后插件会记住。

## 界面：3 个工作区 + 画布工具 + 设置

顶部横向排列「① 准备 — ② 检查 — ③ 导出」，可以自由切换，不是强制逐步完成的向导。没选画板进「准备」，选了画板直接进「导出」；首次使用会先提示导入 ICC，可跳过。右上角分别是画布工具和齿轮设置，外观跟随 Figma。

使用同一套界面：常用项直接可见，专业项按需展开，记住展开状态。收起不会重置已选设置；有非默认专业配置时显示「已自定义」。ICC 缺失和检查状态始终保留在导出页，详细影响按需查看，不反复展示介绍文案。

| 位置 | 做什么 |
|---|---|
| ① 准备 | 选印刷品类型（画册、名片、海报、折页、包装、大幅喷绘），自动带好尺寸、页数、出血；「更多尺寸选项」里有单位、页边距、安全区、四边出血、折页参考线、对页排列、1:N 比例、名称、保存常用尺寸；给已有画板加出血；CSV 批量建画板 |
| ② 检查 · 问题 | 分开列出错误、风险和提示，不给任意质量评分；检查分辨率、出血、安全区、细线、小字、四色黑小字、色域、总墨量、缺字体等，可修复或定位；检查标准可修改 |
| ② 检查 · 印刷预览 | 对比滑块、印刷效果、原稿、C / M / Y / K 分色、墨量、超色域、纸张白模拟，可逐页切换 |
| ② 检查 · 颜色 | 每个颜色按方案自动转换，也可逐个改为自定义 CMYK、专色、刀线 / 工艺、叠印；链接进入色板与颜色映射管理 |
| ② 检查 · 文字 | 全部保留文字 / 按图层设置 / 全部转曲 |
| ③ 导出 | 页面摘要、检查状态、印刷方案、格式、出血、裁切线和文件名；缩略图排序支持拖动或前移／后移按钮；专业选项按需展开；出血不足时提醒并可补足 |
| 印刷方案 | 把 ICC、渲染意图、黑场补偿、单色黑 / 灰色只用 K / 四色黑、总墨量、PDF 标准、透明拼合、自动修复打包成方案。内置胶印铜版纸、胶印胶版纸、报纸 / 老设备、数码快印、屏幕查看；可把当前设置存为自己的方案，导入导出 JSON |
| 专业设置 | 拼版、文字、图片压缩、文件输出、印刷标记；全部专业设置内有四边出血、自动延伸、成品框线、标记线宽、刀线识别与规则、刀版输出、专色策略、书签、超链接、文档信息、密码、RGB 屏幕版和输出缩放 |
| 拼版方式 | 用图示选择不拼版、对页跨页、骑马钉（含从右往左）、一版多拼、正反面；一版多拼和正反面会预览每张排几个、共几张 |
| 画布工具 | 实物尺寸测量与修改、CMYK 上色、色卡标注、页码、替换 / 放大图片、缩回实际尺寸、纸盒刀版生成；仅展开当前工具，操作修改画布，而不是只修改输出 |
| 设置 | 界面语言（含跟随系统）、尺寸单位、外观说明；管理印刷方案与 ICC、色板库、颜色映射表及 JSON 预设。无画板选择或 RGB 输出时也可管理资源；JSON 不含 ICC 和色板 |

未检查或有风险时，导出前会要求确认；允许跳过检查，但不保证文件适合送印。若启用最低图片分辨率限制，接受风险也不会绕过它。改稿后请重新检查，并与印刷厂核对要求。

## 开发

插件使用 TypeScript。界面由 React 和真正的 [Arc UI](https://uiarc.dev) 组件搭建，包括按钮、输入框、选择器、开关、标签页、折叠卡片、对话框和进度条。组件源码位于 `src/components/arc/`；`src/ui/views.tsx` 负责组合页面，`src/ui/layout.css` 只处理布局与印刷预览图形，原有颜色转换和文件导出逻辑仍在 `src/pdf/`。

构建会把 React、Arc 样式、图标和 LittleCMS WASM 一起打包进 `dist/ui.html`，运行时不加载 CDN，也不需要网络。字体使用系统字体，以保持离线使用。

```bash
npm install
node build.mjs          # 生成 dist/；同时用 OpenCC 生成繁体中文
npx tsc --noEmit        # 类型检查
node test/workbench.mjs # 启动根目录静态服务器（4173）后跑界面与真实 PDF 下载回归
node test/run.mjs       # 用测试 PDF 跑完整导出流程
node test/features2.mjs # PDF/X-1a、X-3、四边出血、骑马钉、一版多拼、正反面、按比例放大
node test/raster.mjs    # CMYK / RGB / 灰度 TIFF、JPEG、PNG
```

- 测试用的 ICC：Adobe 的许可不允许随代码分发，所以仓库里没有。跑测试前请把 `JapanColor2001Coated.icc` 放进 `test/fixtures/`。
- 测试页：用本地服务器打开 `test/harness.html`，它会模拟 Figma，可以在浏览器里点完整个界面。
- 界面回归需要 `agent-browser`，不依赖 ICC；通过真实点击和键盘操作验证语言、单位、资源入口、专业设置持久化、风险确认、精确数值与专色名输入及导出参数。`node test/preview.mjs` 可打包实际界面与测试画板供评审；预览不连接真实 Figma，样例不能用于送印。
- 翻译：翻译表在 `src/i18n/dict.ts`。第一列是简体中文原文，后面依次是英、日、韩、西、德、法。新增界面文字后，在测试页切换语言，可以列出漏翻的条目。
- 功能对照：竞品调研和功能对照见 [FEATURES.md](FEATURES.md)。
