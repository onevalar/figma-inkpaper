你可以：
• 为名片、海报、画册、折页及包装准备尺寸、出血和参考线。
• 检查图片分辨率、细线、小字、缺字体等印刷风险，并定位问题。

开始使用：
1. 选择要导出的画板。
2. CMYK 输出前，导入印刷厂提供的 ICC 配置文件，并确认印刷方案。
3. 检查并处理风险，设置格式、出血和文件名，然后导出。
4. 把输出文件交给印刷厂预检、确认，必要时打样。

## English description (ready to paste)

Inkpaper brings print preparation, checks and export into Figma. Color conversion and file generation run locally. The plugin has no network access and requires no plugin account.

• Prepare business cards, posters, booklets, folded layouts and packaging with dimensions, bleed and guides.
• Check print risks such as image resolution, thin strokes, small text and missing fonts, and locate affected layers.
• Import ICC profiles and configure CMYK, spot colors, overprint and color mappings.
• Preview separations, ink coverage and print color effects.
• Configure crop marks, imposition and PDF/X output options; export PDF, TIFF, JPEG or PNG.
• Use page numbering, physical-size measurement and box dieline tools.

To start, select frames, import the ICC profile supplied by your printer for CMYK output, check risks, configure your export and generate files. Have your printer preflight the output and confirm it before production.

Limitations: third-party ICC profiles and commercial spot-color libraries are not included. Without an ICC profile, ordinary CMYK output is approximate; PDF/X output requires CMYK mode and a valid ICC profile. Screen previews cannot replace a proof. PDF/X-1a and X-3 exports may rasterize an entire page, including text, when transparency needs flattening. Selecting a PDF/X output option is not independent certification of conformance. Confirm actual output using your printer’s professional preflight workflow. Continuing after a warning does not establish print suitability.

Eight interface languages: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, German and French.

Privacy: no designs or usage logs are sent to the developer. ICC profiles, swatches, presets and preferences use Figma plugin storage. Frame print metadata, text modes and explicitly saved color mappings are stored in the Figma file and shared with it. External ICC help links open in your browser. Figma’s own storage and collaboration follow Figma’s service policies.

Support: onevalar@gmail.com. Include the plugin version, platform, reproduction steps and export settings. Please do not send confidential design files.
